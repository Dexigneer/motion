# Analýza referenčného videa

**Súbor:** promo „Imagine Art 2.0 edit“ (Klickpin) · 720×540 (4:3) · 30 fps · 42,07 s · AAC 44,1 kHz
**Metóda:** rozbor po snímkach (6 fps na kľúčových úsekoch, 2 fps celé video) + RMS hlasitosť zvuku v 0,5 s oknách.

## 2. Vizuálny jazyk
- **Paleta:** biela s jemným fialovým nádychom, akcent fialová→modrofialová, gradient (aurora) v rohoch.
- **Typografia:** jeden grotesk (Inter-like), stredná hrúbka, malé veľkosti (~5 % výšky), veľa prázdneho miesta. Výnimka: obrie „Introducing“.
- **Kompozícia:** všetko centrované, jeden prvok naraz, veľa vzduchu.
- **Hĺbka:** gradient v pozadí, mäkké tiene pod kartami, motion blur pri každom pohybe.

## 3. Pohyb a tempo
- Takmer **každý prechod je s rozmazaním v smere pohybu** (whip, zoom, focus pull).
- Easing: rýchly štart, dlhé spomalenie (expo/power3.out); odchody zrýchľujú (power.in).
- Text zostane čitateľný **1–1,5 s** po dokončení, nikdy nie menej ako ~0,8 s.
- Rytmus: krátke 1–2 s beaty sa striedajú so zhlukmi rýchlych strihov (logo remix, montáž) → divák nezaspí.

## 4. Zvuk
- **Hudba** nepretržite od 0 s, RMS ~ −16 dBFS, svieža, popová; končí okolo **38 s**, endcard je **v tichu**.
- **SFX** (lokálne špičky −8 až −11 dB): 5,5 s (whoosh „Introducing“), 7,0 s (logo), 11,5 a 12,5 s (UI pop), 15,5 s, 17,5 s (klik + burst), 23 s, 25,5 s (karty), 28,5–34 s (sada klikov/popov pri ťahoch štetcom).

## 5. Čo prenášame, čo meníme
**Prenášame (v inom poradí):** focus-pull slová, inline kapsula, kurzor-klik, whip blur, obrie orezané písmo cez gradient, orbit písmen okolo loga, rýchly remix loga, UI dock, písací stroj + burst šípok, sken odhalenia, text → karta → karusel, zvýrazňovacie ťahy, iris, odrážajúce sa logo, flip endcardu.
**Meníme:** iný produkt a príbeh, teplá „atramentová“ paleta namiesto fialovej, serif + grotesk, bez fullscreen fotiek, malé obrázky = placeholdery, iný tagline a iná dramaturgia (problém → zvrat → dôkaz → logo).
